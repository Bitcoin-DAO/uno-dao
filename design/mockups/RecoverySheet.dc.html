Come recuperare i fondi

  2. Crea un nuovo wallet importando il descrittore: QR o testo.
  3. Controlla che le 5 impronte coincidano con la tabella.

How to recover the funds
  1. Install Sparrow or another wallet that reads descriptors.
  2. Create a new wallet by importing the descriptor: QR or text.
  3. Check the 5 fingerprints match the table.
  4. Build the transaction and sign it with 3 council seeds.
  5. Broadcast it. No UNO website or server is needed.
