## [n] · Language

1. The binding text of this charter is in [language], as set in the DAO's settings (`charterLanguage`). Its fingerprint in the settings (`charterSha256`) is of that text.
2. Translations into [languages] are provided for convenience. Where a translation and the binding text differ, the binding text applies.
3. Changing the binding language is a rules change, voted on like any other change to this charter.
