# site/

The DAO's own static files: an about page, images, anything served next to the app.
Everything here is copied into the built site as it is, at the same path (`site/about.html` becomes `<site>/about.html`).

This folder belongs to the DAO, like `config/`. Updating btc-dao never touches it.
This note (`site/README.md`) is not copied. Two names are reserved for the app: `index.html` and `dao.json`.
